          What LIVE and SIMULATED mean
          
        
            Configuration presence only — credential values are never returned. LIVE means a
            real credentialed connection is configured; SIMULATED means the action type has
            no external execution adapter by construction.
          
        
        
        
      
        

    
        
      
        
        
        
          
        Action Authorization
        
          
        One authorization pipeline, six action types.
        
          
        
            ClaimGate authorizes a typed ProposedAction, not just an eSign send. SIGN_DOCUMENT
            is the only action type with a real external execution adapter; every other type
            below is demonstrated but never actually executed.

              LLM does not control policy.

              Browser has no execution credentials.
              Signing and model credentials stay server-side; the browser never receives them.
            
        
            
        
              Agent has no eSign tool.
              The semantic provider has no import path to the eSign client or the action execution registry.
